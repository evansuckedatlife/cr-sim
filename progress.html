What each number means

Written out because most of these are easy to misread, and two of them were misread on this project already.

Lift vs control
The only number that says whether the agent is any good. It plays a uniform-random opponent over 40 fixed battles, and a random agent plays the same 40. The gap is divided by how much the random agent’s own score bounces around, so the unit is standard deviations of noise.
0 means no better than random, whatever the win rate says. Roughly 0.5 is a real effect. Below about 0.25 is inside the noise and should not be believed.
Win rate vs control win rate
Share of those 40 battles each side won. Both look low because most 120-second matches end 0–0 with no tower falling, and a draw is not a win — so the control’s own rate, not 50%, is the bar to clear.
Explained variance
How much of the match outcome the critic can actually predict, on a scale where 1 is perfect.
0 means no better than guessing the average every time. It sat at 0.06 on the previous run, which is the likeliest reason a policy committed hard to a strategy that never got stronger. Watching this climb is the point of the current reward design.
Entropy
How undecided the policy is. It starts near the maximum for 720 possible plays and falls as the agent develops preferences.
Falling entropy means commitment. That is only good news when lift rises with it — committing without improving is how a policy converges on one useless move it repeats forever.
Value loss and return spread
Value loss is the critic’s squared error, and it is meaningless alone because it scales with the spread of what it is fitting. An error of 5 is dreadful against returns that vary by 0.5 and unremarkable against returns that vary by 3.
This exact confusion cost real time here: a value loss of 5 was called a broken critic when it was only a different reward scale. Always read it beside the spread.
Rollout win rate
The agent’s win rate during training. The flattering number and the misleading one: measured while the policy is still exploring, on whatever battles it drew, and on this project it has run about eighteen points optimistic — reporting 55% for a policy that evaluated at 37%.
Shown for completeness. Steer by lift.
Pass rate
How often the agent chose to play nothing when it could have played something. Passing is the one action never punished, so a run that quietly collapses into always passing looks healthy on every other metric.
Throughput
Decisions per second and matches finished. Each decision covers 30 engine ticks — 1.5 seconds of match time — and each match is 120 seconds.
